# Virtual Pet Game 🌱

A virtual pet game made with **Python** and **Pygame**. Take care of a little plant, explore its rooms, and see how its story unfolds over time.

This is my **third Python learning project**. I built it step by step while learning programming and game development.

## Features

- **New Game** and **Continue** options, with progress saved in a local JSON file.
- An animated introduction with **Skip** and **Exit** buttons.
- Five areas: the main room, **Food**, **Fun**, **Sleep**, and **Care**.
- Four pet stats: **Hunger**, **Happiness**, **Energy**, and **Health**.
- Day and evening backgrounds, sleep and wake-up behavior, and events based on real-world time.
- Animated characters, interactive buttons, music, and sound effects.
- A **Game Over** sequence if the pet's hunger and health stay at zero for 24 hours.
- A separate ending sequence after the 15-day journey.

## Built with

- **Python** for the game logic
- **Pygame** for graphics, animation, input, and audio
- **JSON** for saving and loading game progress
- **datetime** for real-time gameplay mechanics

## How to run

1. Install Python and Pygame:

   ```bash
   python -m pip install pygame
   ```

2. Download or clone this repository.
3. Open a terminal in the project folder, keeping the `images` and `sounds` folders alongside the Python files.
4. Start the game:

   ```bash
   python main.py
   ```
